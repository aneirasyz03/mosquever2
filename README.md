# Seoul Central Mosque — Digital Prayer Display

A responsive HTML/CSS/JavaScript/JSON-ready mosque information display for GitHub Pages.

## Included
- Responsive modern Gen-Z / Islamic-Korean visual system
- 60/30/10 palette requested by the project
- Live device clock
- Prayer-time API integration
- Device geolocation for prayer-time calculation
- Seoul fallback location
- Countdown to next prayer
- Prayer cards
- Hijri + Gregorian date
- Mosque information display feature cards
- Interactive history timeline
- Directions with Google Maps link
- Mobile/tablet/TV-friendly layout
- Light/dark contrast toggle

## Deploy to GitHub Pages
1. Upload `index.html`, `style.css`, and `app.js` to a GitHub repository.
2. Go to Settings → Pages.
3. Select the branch/root folder.
4. Save and open the generated Pages URL.

## Important
For an actual mosque TV deployment, verify prayer-time calculation method and local time adjustments with the mosque. The browser asks for device location; if permission is denied it falls back to Seoul coordinates.

No backend is required for the basic version.
